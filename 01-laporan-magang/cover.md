Pengelolaan operasional pusat data kolokasi di PT Jawa Pos Media Televisi (JTV) sebelumnya tersebar pada catatan terpisah. Kondisi ini memicu konflik alokasi rak, selisih kontrak, serta lemahnya audit fisik. Laporan Praktik Kerja Lapangan ini memaparkan kontribusi rekayasa pada ekosistem *MSDC Enterprise Resource Planning* (ERP) guna menyatukan alur tersebut. Penulis merancang standardisasi *User Interface/User Experience* (UI/UX) melalui *Design System* *Figma* dan navigasi *2-Tier Sidebar* lintas modul. Penulis juga membangun penuh lima klaster modul *Data Center Operations*. Cakupannya meliputi hierarki fasilitas fisik dan peta rak 42U, konektivitas jaringan, dasbor telemetri termal bersama pemantauan kamera, operasional harian beserta penagihan utilisasi, hingga kontrol akses fisik berbasis *one-time Quick Response* (QR) *code*. Pada tingkat ekosistem, modul ini menyinkronkan kontrak *Application Programming Interface* (API) bersama empat modul tim lain: *CorePlatform*, *CRM & Sales*, *Finance & Accounting*, serta *HR & Service Support*. Secara arsitektural, sistem *decoupled* ini berjalan pada *Laravel 12* modular (*PHP 8.4*) dan *React 18* (*TypeScript 5.6*) dengan pedoman *ISO/IEC 27001:2022*, *ASHRAE TC 9.9*, serta *ANSI/TIA-942-C*. Pengujian fitur otomatis *PHPUnit* pada 11 *suite* uji mandiri lulus 100% meliputi 170 skenario dan 1.149 *assertions*. Verifikasi kontrak API *Postman* (HTTP 200, 422, dan 409) serta *User Acceptance Testing* (UAT) *staging* berjalan sesuai spesifikasi. Sistem ini memperkuat kendali rak dan kesiapan audit JTV.

**Kata kunci:** *Enterprise Resource Planning*, *Data Center Operations*, *Design System*, arsitektur modular, *Laravel*, *React*.

*Colocation data center operations at PT Jawa Pos Media Televisi (JTV) previously relied on scattered manual records. This fragmentation led to rack allocation conflicts, contract discrepancies, and weak physical access audit trails. This internship report documents engineering contributions to the MSDC Enterprise Resource Planning (ERP) ecosystem designed to unify those operational workflows. The author standardized cross-module User Interface/User Experience (UI/UX) through a Figma Design System and a global 2-Tier Sidebar navigation pattern. The author also built all five clusters of the Data Center Operations module, spanning physical facility hierarchies and 42U rack elevation maps, network connectivity, thermal telemetry dashboards with camera surveillance, daily operations and usage billing, and one-time Quick Response (QR) code physical access control. Across the wider ecosystem, the module synchronizes Application Programming Interface (API) contracts with four cross-team modules: CorePlatform, CRM & Sales, Finance & Accounting, and HR & Service Support. This decoupled platform runs on modular Laravel 12 with PHP 8.4 and React 18 with TypeScript 5.6, aligned with ISO/IEC 27001:2022, ASHRAE TC 9.9, and ANSI/TIA-942-C. Automated PHPUnit feature testing across 11 standalone suites achieved a 100% pass rate covering 170 scenarios and 1,149 assertions. Postman API contract checks (HTTP 200, 422, and 409) and staging User Acceptance Testing (UAT) ran according to specification. Overall, the system strengthens rack capacity governance and audit readiness at JTV.*

**Keywords:** *Enterprise Resource Planning*, *Data Center Operations*, *Design System*, *Modular Architecture*, *Laravel*, *React*.
